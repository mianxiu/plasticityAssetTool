# 布尔模式与连续布尔组

## 默认布尔模式

在实体组件的编辑侧栏直接切换四种模式。使用布尔模式前，先在 Plasticity 中选中目标实体，再置入组件。

| 模式 | 缩略图细外框 | 置入结果 |
| --- | --- | --- |
| 独立对象 | 中性灰 | 保留为独立对象 |
| 布尔合并 | 🟢 绿色 | 与选中的目标合并 |
| 布尔减去 | 🔴 红色 | 从选中的目标中减去组件 |
| 布尔相交 | 🔵 蓝色 | 保留目标与组件的相交部分 |
| 连续布尔组 | 🟣 紫色 | 按保存的子部件顺序逐项运算 |

没有有效目标时会拒绝布尔置入。**原位置粘贴始终使用独立对象模式。**

### 组组件与连续布尔

选中 **一个原生组**，点击保存组件：插件读取组名和直接子实体，按列表从上到下保存顺序，通过子部件名称前缀决定操作。

| 名称前缀 | 操作 |
| --- | --- |
| `+` | 合并 |
| `-` | 减去 |
| `&` | 相交 |
| `^` 或无前缀 | 独立对象 |

例如，下面的组件会先把外壳合并到选中目标，再减去内孔，标记块保持独立：

```text
连接件（组）
├─ + 外壳
├─ - 内孔
└─ ^ 标记块
```

置入时先整体定位并确认，再依次计算。计算期间显示步骤、部件名称与耗时，并暂时锁定当前窗口的操作；失败时回滚，成功后可整体撤销。

目前支持 **1–128 个直接子实体**，不支持嵌套组或组内曲线。普通多选不会按名称前缀执行连续布尔。按各步骤颜色显示几何预览仍在 [开发计划](../../TODO.md) 中。
