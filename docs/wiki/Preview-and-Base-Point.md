# 3D 预览与基点

3D 预览右上角显示随视角旋转的 X / Y / Z 方向标注，模型基点显示方向环与局部坐标轴。

## 编辑基点

名称、分类和标签可在编辑面板顶部直接修改。编辑预览用黄色十字显示基点，红 X、绿 Y、蓝 Z 显示置入基点的方向。点击预览左下角的 **编辑基点** 进入独立编辑窗口，**Plasticity 精确拾取** 按钮与 **预览拾取** 放在一起。**预览拾取** 支持端点、边中点和平面中心吸附，可勾选 **按面法线定向**，也可填写 XYZ 坐标和旋转角度、重置方向。编辑窗口使用正交预览：右键拖动旋转、滚轮缩放，确认回传草稿，取消或 Esc 丢弃本次全屏调整；最后点击 **保存修改** 才写入组件。也可使用 **世界原点 / 模型中心 / 底部中心**。

窗口还提供绕局部 X / Y / Z 轴旋转 180°：绕 X 或 Y 反转会翻转 Z 方向，绕 Z 反转会翻转面内方向。

## 离线预览与捕捉范围

离线调整不需要运行 Plasticity。已有几何预览缓存可离线使用，没有缓存时仍需连接 Plasticity 生成一次；坐标和方向输入不依赖预览。吸附来自内核边线和面的预览采样，曲线中点和曲面法线为近似值；平面中心按相连共面网格的面积计算，不吸附到孔洞内的中心。模型中心及底部中心基于预览包围盒；需要精确拓扑捕捉时使用原生精确拾取入口。保存更新原生定位头的位置和方向，保留几何、子部件顺序、布尔配置和组件包数据。编辑期间模型若已变化则拒绝覆盖。

## Plasticity 原生精确拾取

需要原生精确捕捉时，可在基点编辑窗口点击 **Plasticity 精确拾取**，关闭预览编辑窗口并进入 Plasticity 原生拾取：无需选中视口对象，插件自动加载库里的组件作为临时参考；确认后立即保存基点并移除临时模型、恢复原选择，Esc 取消。临时参考不执行默认布尔或组内布尔。此功能需要更新内嵌插件并重启对应 Plasticity 窗口。

## 内核捕捉

基点编辑器默认使用 **内核捕捉**：打开后自动加载原始边端点、直线中点和曲线参数中点，替换预览网格的端点与边中点，保留平面面中心；无需单独开启实验选项。曲线参数中点位于原曲线上，但不保证是半弧长位置。关闭“吸附端点 / 边中点 / 面中心”会关闭全部点吸附。任意曲面位置和法线仍使用预览网格；需要完整原生捕捉时使用 **Plasticity 精确拾取**。旧缓存按需补充捕捉点，获取失败会提示并回退到预览吸附，获取后的点可离线复用。

## 其他版本的自动格式检测

当前实机验证版本仍为 26.1.3。25.2.5 提供的原生剪贴板样本采用不同的封装；当前源码可解析其中的单实体和多实体几何，但实际保存、置入及基点仍需在该版本验证，旧 Release 不包含此改动。

更新后台与内嵌插件后，在目标 Plasticity 中选中一个简单测试实体，点击组件库顶部 **⚙ → 自动检测模型格式**。程序以两组预设坐标和方向调用原生复制接口，仅在内存中捕获结果，不写系统剪贴板、不保存或关闭文档。检测结果自动下载为 `plasticity-model-format.json`；无需手动计算坐标。

只有两组原生输出都匹配且字段不重叠、未覆盖对象数量时，才保存校准结果并开放对应版本的离线基点编辑。若该版本保存的是方向向量而非四元数，允许编辑位置，保留原方向，暂不开放离线旋转。校准信息随组件包、批量导入与整库备份恢复保留。未知结构只输出诊断，不猜测字段；不同封装之间暂不拼接基点头。内部原生接口变化仍可能需要适配，不能保证所有未来版本无条件兼容。

## 自定义缩略图操作

组件编辑预览框左上角提供方形缩略图入口：左键选择，右键打开菜单后选择“清空缩略图”；键盘聚焦后也可按 Shift+F10 打开菜单。JPEG、PNG、WebP 图片超过 512×512 时等比例缩小至该范围，不裁切、不放大小图；小 JPEG 保留原始图片数据，其他格式转换为 JPEG，透明区域使用白色背景。选择后仍需保存修改。
