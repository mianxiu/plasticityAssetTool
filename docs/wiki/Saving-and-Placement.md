# 保存与原生置入

在 Plasticity 中选中对象，完成当前建模操作，再打开组件库并点击 **保存组件**。插件会在保存时识别实体、曲线、混合对象，以及符合条件的原生组；仅打开面板不会读取组信息。

保存表单的 **组件基点** 可选“世界原点”或“视口拾取”。拾取使用原生 Copy with Placement 命令及捕捉，面板收起后在视口确认，按 Esc 取消；两分钟未完成会取消，组件不写入数据库。普通组件和连续布尔组都支持，组的全部子部件共用一个基点。从剪贴板保存时保留其中已有的基点。

| 操作 | 效果 |
| --- | --- |
| **Tab** | 打开 / 关闭内嵌面板 |
| **点击缩略图** | 直接进入原生置入流程 |
| **缩略图上按住右键并拖动** | 临时旋转查看模型，松开恢复缩略图 |
| **点击「编辑」** | 打开可滚动侧栏，直接修改名称、分类、标签、备注和置入模式等信息 |
| **编辑预览中右键拖动 / 滚轮** | 旋转 / 缩放正交 3D 预览 |
| **视口内确认 / 取消** | 完成 / 取消当前置入，使用 Plasticity 原生操作 |

普通多选会保存为一个包含多个对象的组件。曲线和混合组件使用独立对象模式，不显示实体布尔设置。显式的「仅复制到剪贴板」仍可用于其他工作流，但不属于默认交换方式。

更多编辑操作见 [3D 预览与基点](Preview-and-Base-Point.md)。
