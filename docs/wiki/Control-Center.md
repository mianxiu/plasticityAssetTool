# 面板与控制中心

**优先展示组件。** 左侧导航可固定展开或鼠标悬停展开；组件卡片有 37 档大小，调整后自动保存。面板可固定显示，或以鼠标位置为中心打开；靠近窗口边缘时会自动调整位置。面板边框跟随 Plasticity 的 Accent Color。

**多窗口分别操作。** 每个内嵌面板绑定所在的 Plasticity 窗口；独立后台界面可以跟随最近激活的窗口，也可选择固定目标。

**后台由托盘控制。** 同一安装目录仅运行一个实例，重复启动会复用已有后台。关闭控制窗口不会退出后台；手动启动的后台也不会随 Plasticity 关闭。双击托盘图标打开控制中心，右键菜单可以暂停连接或退出。后台离线后，Tab 面板会明确提示未连接。

控制中心默认地址为 [`http://127.0.0.1:15150/?control=1`](http://127.0.0.1:15150/?control=1)，提供中文 / English 切换。

控制中心标题下方和托盘右键菜单顶部显示工具版本，统一来自 `backend/version.py`。`-dev` 表示开发版；控制中心显示当前运行后台返回的版本，旧后台未提供版本时显示“—”。

## 更新哪一部分

控制中心的 **更新状态** 自动区分三种更新，也可点击 **检查更新** 立即检测。本地检测不下载发布包或自动安装。

| 部分 | 生效方式 |
| --- | --- |
| 界面 | 完整构建后自动热更新；编辑或置入期间等待安全时机，不刷新 Plasticity |
| 后台 | 文件与当前运行代码不同则提示“需重启后台”；只重启组件库后台，Plasticity 可以保持打开 |
| 内嵌插件 | 只有安装入口与当前插件生成结果不同才显示“更新插件”；此时才需要自行保存、关闭对应窗口并确认 UAC |

UI、文档和普通后台修改不会触发内嵌插件安装。插件检测会自动刷新进程状态，入口已是最新版时仅显示“正在运行”，不会要求关闭窗口。没有可验证备份的安装会单独提示检查，不能判断为已是最新版。
