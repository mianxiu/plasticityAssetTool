# 安装、更新与恢复内嵌插件

启动后台后，在控制中心的“更新与安装”完成操作，无需手工输入安装命令。Windows 程序发布包自带 `PluginInstaller.exe`；EXE 启动后台时不会擅自安装插件。

## 安装步骤

安装前请阅读 [第三方声明与使用风险说明](../../DISCLAIMER.md)。本工具非官方产品，尚未取得针对其注入方式的明确官方授权；入口备份不等同于建模文档备份，也不能代替宿主许可。请先确认所需权限，备份文档与组件库，并使用独立测试文档验证。

1. 解压完整发布包，运行 `plasticityassettool.exe`，打开控制中心。
2. 打开“更新与安装”，后台自动读取常见目录、Windows 安装记录及运行进程，列出版本、目录、运行状态和插件状态。需要时点击“重新检测”。
3. 如果没有找到，展开“高级安装选项”，输入完整安装路径，再点击“检测目录”。可以输入 `app-26.1.3` 目录，也可以输入其上一级 Plasticity 目录。
4. 需要安装或更新时，自行保存文档并关闭对应版本的所有 Plasticity 窗口；运行状态会自动刷新，也可点击“重新检测”。后台不会关闭窗口或替你处理未保存文档。
5. 点击该版本的“安装插件”或“更新插件”，确认版本和目录，继续安装流程。
6. 在独立安装窗口检查来源、目标文件及备份位置，点击继续，并自行批准 Windows UAC 权限请求。
7. 后台显示完成状态后，重新打开 Plasticity。Tab 打开、再按 Tab 关闭组件面板。

默认自动安装仅开放已实测的 **Windows / Plasticity 26.1.3**。在后台勾选 **允许测试其他版本** 后，可以安装或更新检测到的未验证版本，设置自动保存，重启后台后保留。其他安装位置可输入完整目录检测。开放测试只解除版本限制，仍检查入口结构、运行状态及备份；不代表该版本已兼容。取消勾选会重新禁用未验证版本的安装和更新，有效原始备份仍可恢复。权限请求无法被后台自动批准；取消后显示“操作已取消”，可以再次开始。

## 安装状态

| 状态 | 含义与操作 |
| --- | --- |
| 未安装 | 支持且没有运行窗口时，可以安装 |
| 已是最新版 | 当前入口与本后台生成的插件完全一致 |
| 可更新 | 已识别旧插件及有效备份，可以更新 |
| 已安装，但缺少可验证备份 | 没有匹配当前入口的备份，或入口被其他操作修改；不自动覆盖 |
| 正在运行 | 先自行保存并关闭此版本所有窗口，再重新检测 |
| 此版本尚未支持自动安装 | 未经过实机验证，可勾选“允许测试其他版本”开放测试安装 |
| 未验证版本 | 已开放测试；实际兼容性需要在该版本验证 |

检测到的状态会在操作后更新。若在后台页面之外打开或关闭 Plasticity，运行状态会自动刷新，也可点击“重新检测”；点击操作时也会重新校验运行状态。

## 备份与恢复

安装和更新自动在 `.runtime/plugin-backups/` 保存唯一名称的 `.js` 与 `.manifest.json`，记录目标路径和修改前后 SHA-256。后台也识别本安装目录 `.runtime/` 中早期版本生成的有效备份。

“恢复原始入口”恢复已验证、未安装插件的入口，而不是只退回上一版补丁。多次更新的回滚备份保留；组件数据库不受影响。如果入口或备份不匹配，操作会拒绝，以免覆盖其他修改。

更新程序时保留 `library/` 和 `.runtime/`。换到新目录但没有迁移旧 `.runtime/` 时，后台可能找不到原插件备份，此时不会强制更新。源代码目录若没有安装器 EXE，会先用 Windows .NET Framework 编译器构建；发布包无需现场编译。

安装任务一次只允许一个；管理员安装器还按目标入口加互斥锁。申请权限后会再次验证版本、目标摘要和运行进程。任务进行中不能退出后台，需先在安装窗口完成或取消。
