# 导入、导出与备份

## 导出单个组件

1. 点击组件卡片“编辑”。
2. 点击“导出组件包”。
3. 保存 `.patasset`，可交给其他安装了兼容插件的用户。

原始模型、名称、分类、标签、备注、默认置入规则及连续布尔顺序会随包导出。手动 JPEG 可随包导出，自动几何预览缓存不随包导出。

## 多选导出

1. 右上角“导出 → 多选组件导出”。
2. 勾选组件；此时点击缩略图仅切换选择，不置入模型。
3. 可“全选当前结果”或“清空选择”，然后点击“导出所选”。
4. 下载 `plasticityassettool-components.zip`，点击“完成选择”退出选择模式。

“全选当前结果”包含当前筛选列表的全部结果，不限于屏幕上可见的卡片。分类、分组和搜索之间切换会保留同一库内的选择；切换库或归档视图会清空选择。

## 按分类或整个库导出

| 操作 | 导出范围 |
| --- | --- |
| 选中侧栏分类 → 导出当前分类 | 当前库中该分类的所有组件，包括不同分组；不受搜索、类型及分组筛选限制 |
| 全部组件视图 → 导出当前库全部组件 | 当前库所有未归档组件 |
| 已归档视图 → 导出当前库全部组件 | 当前库的已归档组件 |

这些操作不跨多个库，也不是完整数据库备份。单次最多 10000 个组件，下载 ZIP 内为独立 `.patasset` 文件。

## 批量导入与冲突处理

1. 在组件库选择接收的资产库及分组。
2. 点击 **导入组件包**，一次选择多个 `.patasset` 或组件 ZIP；本工具的批量导出 ZIP 可直接选择，无需解压。
3. 校验完成后查看预览：组件、名称冲突、相同模型和包内重复项。
4. 逐项或批量选择 **跳过、保留两份、覆盖**；覆盖时选择具体目标，再确认导入。

相同模型及包内重复默认跳过，其他默认导入；同名保留两份时自动加序号。匹配范围为当前库和当前分组，包含归档组件。新导入创建新 ID 和时间，保留分类、标签、备注、模型字节与连续布尔配方，不重建来源库/分组树；覆盖修改所选目标。取消预览不修改数据，确认后在一个数据库事务中提交。

导入后连接 Plasticity 可重新生成自动预览。组件 ZIP 与整库备份 ZIP 用途不同，整库备份必须在控制中心恢复。详细结构见 [文件格式](File-Formats.md)。

## 整库备份与恢复

控制中心 → **备份与迁移** → **下载整库备份**，可保存所有资产库、分组层级、组件 ID、归档状态、名称、分类、标签、备注、原始模型（含基点与方向）、布尔配方和自定义缩略图。备份通过 SQLite 一致快照制作；生成的几何缓存不包含在备份中，可重新生成。面板偏好、安装配置与宿主建模文档保持本机原状。

**选择整库备份恢复**会先展示库、分组及组件列表。点击“确认替换并恢复”后，先在 `.runtime/library-backups/` 保存当前库的回滚 ZIP，再用一个数据库事务替换全部库数据；失败不留下部分恢复结果。成功提示包含回滚文件位置，该 ZIP 可按相同流程恢复。整库恢复会移除当前库中不在备份内的组件，因此分享组件请使用批量导入。

## 容量与操作限制

预览有效期 10 分钟，库数据发生变化后需重新预览。模型任务运行时不能提交导入或恢复。每次上传合计不超过 512 MB，最多 10000 个组件，展开后的模型与图片合计不超过 2 GB；整库备份 ZIP 同样限 512 MB。更大的库需分批导出组件。上传包不会解压到用户指定的磁盘路径，也不会执行其中的脚本。

## 手动迁移与本机设置

也可在所有读写操作结束、通过托盘退出后台后，复制整个 `library/` 进行离线备份。此方式包含几何缓存；控制中心生成的整库备份不含可重建缓存。如需保留面板设置和插件恢复文件，另行保留 `.runtime/`，它含本机路径及运行状态，不作为通用组件交换包。更新程序时保留原有 `library/` 与 `.runtime/`。
