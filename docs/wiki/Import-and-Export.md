# 导入、导出与备份

## 导出单个组件

1. 点击组件卡片“编辑”。
2. 点击“导出组件包”。
3. 保存 `.patasset`，可交给其他安装了兼容插件的用户。

原始模型、名称、分类、标签、备注、默认置入规则及连续布尔顺序会随包导出。手动 JPEG 可随包导出，自动几何预览缓存不随包导出。

## 多选导出

1. 右上角“导出 → 多选组件导出”。
2. 勾选组件；此时点击缩略图仅切换选择，不置入模型。
3. 可“全选当前结果”或“清空选择”，然后点击“导出所选”。
4. 下载 `PlasticityAssetTool-components.zip`，点击“完成选择”退出选择模式。

“全选当前结果”包含当前筛选列表的全部结果，不限于屏幕上可见的卡片。分类、分组和搜索之间切换会保留同一库内的选择；切换库或归档视图会清空选择。

## 按分类或整个库导出

| 操作 | 导出范围 |
| --- | --- |
| 选中侧栏分类 → 导出当前分类 | 当前库中该分类的所有组件，包括不同分组；不受搜索、类型及分组筛选限制 |
| 全部组件视图 → 导出当前库全部组件 | 当前库所有未归档组件 |
| 已归档视图 → 导出当前库全部组件 | 当前库的已归档组件 |

这些操作不跨多个库，也不是完整数据库备份。单次最多 10000 个组件，下载 ZIP 内为独立 `.patasset` 文件。

## 导入组件

1. 如果收到批量 ZIP，先解压。
2. 在组件库选择接收的库及分组。
3. 点击“导入组件包”，选择一个 `.patasset`。
4. 多个单包目前逐个导入；导入后连接 Plasticity 可重新生成自动预览。

导入创建新的组件 ID 与时间记录，保留分类等编辑信息和连续布尔顺序。不会自动创建包来源的库/分组树，也不保留归档状态。文件格式细节见 [文件格式说明](File-Formats.md)。

如果导出入口提示后台版本较旧，请通过托盘退出后台，再运行启动入口加载更新。关闭管理窗口只是关闭窗口，不退出后台；不要在组件读写过程中直接替换数据库。

## 完整备份与迁移

1. 等待当前保存、导入导出及模型操作结束，通过托盘退出后台。
2. 复制安装目录下整个 `library/` 到备份位置。
3. 如需保留本机面板设置与插件恢复文件，另行备份 `.runtime/`；它含本机路径和进程状态，不作为通用组件交换包。
4. 在目标安装目录退出后台后恢复 `library/`，再启动后台。

恢复会替换目标目录已有数据库，请先备份目标 `library/`。完整数据库备份保留所有库、分组、组件 ID、时间、归档和预览缓存；按分类/整库导出仅交换模型组件，不具有这些完整恢复能力。

源码更新或程序 ZIP 不包含个人模型。新旧版本迁移前建议保留数据库副本；模型置入兼容性仍取决于 Plasticity 内部序列化版本。
