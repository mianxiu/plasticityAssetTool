# 多窗口、断连与布尔回滚

## 本轮变更

原生任务同时绑定窗口 HWND 和工作连接的 token。窗口关闭后句柄复用、主页面导航或调试连接更换时，旧任务不交给新的上下文执行。独立后台的“跟随激活窗口”如果找不到有效目标，会拒绝操作，不回退界面中残留的旧目标。

已经投递的任务如果超时，或请求方中途离开，后台保留该窗口的任务锁。收到匹配回执后释放；其他窗口不受该锁影响。没有投递的超时任务直接删除，后续连接也不能迟到执行。连接恢复只重发已有回执，不重放模型命令。

前端忽略旧 WebSocket 的迟到状态与消息；主动断开时立即清理待响应请求和计时器，拒绝未完成请求，避免页面继续显示连接成功。

连续布尔在执行前校验步骤顺序、操作类型及对应原生枚举，缺少接口时先拒绝。置入与后续布尔继续注册在同一个原生命令中；计算失败后直到原生执行器完成回滚，才清除当前窗口的输入锁。

## 验证范围

| 场景 | 自动验证 |
| --- | --- |
| 两个窗口分别置入 | 任务与回执隔离，不消费对方任务 |
| 工作连接更换 | 已投递和未投递任务都不转交新连接，旧轮询不夺回连接 |
| HTTP 回执发送失败 | 重连保留回执，不再次执行置入 |
| 收到任务期间页面导航、调试断开或窗口销毁 | 旧上下文不执行，执行前再次校验 |
| 已投递任务超时或请求取消 | 阻止重复投递，匹配迟到回执后释放，不锁定其他窗口 |
| 跟随目标已关闭 | 拒绝回退旧界面目标 |
| WebSocket 重连及主动断开 | 不重放操作、忽略旧事件、立即清理请求 |
| 连续布尔第二步异常、空结果或结果分组失败 | 在事务模拟中恢复原始对象与选择，回滚期间保持锁定 |
| 用户在定位阶段取消 | 不启动计算，清理请求；不阻止其他窗口操作 |

本轮全套 Python 测试共 188 项通过，另执行原生传输、组运算和计算进度脚本，前端生产构建通过。测试使用临时数据库和隔离的窗口／原生事务模拟，不操作现有建模文档。

**回滚测试验证的是插件对原生事务的调用与等待约定，尚未在真实 Plasticity 内核中强制制造上述故障。** 真实内核行为、窗口退出期间的恢复以及更多版本兼容性仍需独立测试文档实机验证；不据此宣称所有内核失败场景均已通过。

## 操作结果尚未确认时

先检查目标视口，确认置入是否已经开始或完成；如原生工具仍在运行，自行确认或取消该操作。不要连续点击重试。后台收到原工作连接回执后自动解除任务锁。

若回执始终无法恢复，应先自行处理文档，再重新打开目标 Plasticity 窗口以建立新会话。插件不会自动结束用户工具或关闭文档。

## 加载本轮修复

后台代码需通过托盘退出旧后台后重新启动。内嵌工作脚本需在控制中心更新插件，并在用户自行处理文档、关闭相应版本窗口后安装，下次打开 Plasticity 加载。仅重新打开 Tab 不会更新宿主中的原生工作脚本。

## 基点拾取实机验证（2026-10-06）

在 Windows 上使用 Plasticity 26.1.3 独立测试副本，保留正式窗口文档。验证原生接口与实际视口点击，不以模拟测试代替实际拾取。

| 场景 | 实测结果 |
| --- | --- |
| 实体拾取新基点并经后台保存 | 原生定位头发生变化，其后的几何字节不变 |
| 保存后重新读取、导出 `.patasset` 并导入临时库 | 完整模型字节保留，包含基点 |
| 编辑时重新拾取、重设世界原点 | 只修改定位头，几何保留；世界原点恢复成功 |
| Esc 取消实体拾取或修改 | 原选择恢复，已存模型不变，后续读取正常 |
| 两个子实体组成的组拾取共同基点 | 子部件编码顺序及 `+` 合并、`-` 减去配置保留 |
| Esc 取消组拾取 | 恢复组选择，原生接口可继续使用 |
| 组拾取与取消期间检查系统剪贴板序列 | 序列不变，未写入系统剪贴板 |

实测发现原生 Copy with Placement 不接受仅选中组的状态。拾取前临时展开组内实体，完成或取消后恢复组选择。原生执行器还会在命令 `execute()` 返回后清理选择，因此恢复选择和再次校验组之前，需要等待该命令退出执行器；等待有上限，未退出时拒绝保存。

本次完整自动测试 201 项通过，补充组展开、取消恢复及延迟清理的回归验证。临时测试组件已移除。以上验证不包含实际连续布尔计算结果、更多版本兼容性或已移动／缩放参考模型的坐标换算，相关限制仍按 README 描述。

### 编辑基点的自动参考模型

编辑侧栏的两个基点操作改用库里保存的模型，无需选中原组件。插件在同一原生命令内载入临时参考，拾取前聚焦参考模型；完成或取消时删除本次导入的对象，再用原生取消结束临时事务，最后恢复操作前的选择。不调用 Undo 撤销用户操作，也不执行组件的布尔配置。后台只替换保存模型的定位头，原始几何、子部件顺序和配置保持不变。

在独立 Plasticity 26.1.3 副本实测无选中对象时加载、视口点击确认、Esc 取消与重设世界原点：临时模型移除，原选择恢复，主分区体数量恢复原值，系统剪贴板序列不变。自动验证还覆盖导入部分完成后抛错时的清理、旧插件能力拒绝和窗口任务路由。正式窗口需更新内嵌插件才能使用新接口；仅更新网页不能加载宿主中的原生代码。

本次自动参考功能的全套测试为 203 项通过，前端生产构建通过。

### 离线编辑基点（2026-10-06）

用隔离的 26.1.3 副本原生 copy(Vector3(123,456,789)) 验证定位头前三个 Float64 即 XYZ；构建 10 单位测试盒后，内核网格范围也是 0–10，确认预览和定位头使用相同单位。只修改前 24 字节，保留后续四元数及几何。保存基点与编辑信息使用同一数据库事务及摘要条件，失效草稿不覆盖新模型。网格缓存复制到新摘要，无需重新剖分。

自动验证覆盖离线且连接暂停时读取/保存、非法及过期坐标拒绝、朝向和几何字节不变、包导入导出、Z-up 包围盒位置、预览平移/旋转及缩放后的射线拾取。浏览器实测曲线拾取更新黄色标记，关闭再编辑恢复原保存坐标；未修改用户已有组件。预览拾取为网格近似，不等同于原生拓扑捕捉。
