# Tab 组件库性能验证

2026-10-05，本机浏览器、1280 × 720 窗口（内容宽度 1265 px）、184 px 卡片。测试库使用合成元数据及占位预览，不代表真实复杂三维网格的生成时间。

| 组件数量 | 优化前切换资产库至首屏绘制 | 虚拟网格后 | 创建的卡片 |
| --- | --- | --- | --- |
| 100 | 约 180 ms（首次页面加载） | 约 187 ms（首次页面加载） | 100 → 25 |
| 1000 | 467 ms | 41 ms | 1000 → 25 |
| 5000 | 1193 ms | 131 ms | 5000 → 25 |

这些是同机一次对照测量；首次网页加载和资产库切换是不同测量口径，不能直接互比。Tab 再次打开复用已有面板，150 ms 后才进行同步，先显示缓存内容。

5000 项首次元数据约 2.85 MB；无变化时的后续增量响应约 629 字节。游标绑定后台进程，重启、游标过期或切换资产库时自动读取完整快照。后台保留最多 512 次组件变化记录。

101 个组件，其中一个模型为 64 MB：SQLite 列表读取中位数由 68.3 ms 降至 1.83 ms（各 10 次）。轻量 `asset_metadata` 索引避免访问模型 BLOB 所在行，由 SQLite 触发器在同一事务维护。旧库首次启动需要建立索引，保留模型原始字节。

已验证滚动到第 5000 项、搜索、末尾组件编辑、最小／最大卡片大小，以及隔离 Plasticity 中 Tab 连续开关。自动测试覆盖增量响应、归档移除、过期游标、读取不广播变化、索引迁移及独立读取、虚拟网格边界。

仍未覆盖数万条长备注、真实图片解码压力和大型三维网格旋转；必要时进一步加入服务端分页及搜索。手动启动的正式后台由用户通过托盘退出，重新启动后启用新的索引与增量接口。
