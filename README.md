# plasticityAssetTool

Windows 上的 Plasticity 模型组件库。直接保存选中模型，点击组件后进入 Plasticity 的原生放置流程，在视口里定位、调整并确认置入。默认模型交换不读写系统剪贴板。

后台采用进程级单实例锁：同一安装目录只运行一个服务和托盘，即使重复启动或指定不同端口，也复用已有后台。普通重复启动会打开已有后台的控制窗口，`-Headless` 只复用服务。启动脚本会先检查实例再构建前端；并发启动由系统文件锁保护，异常退出后锁自动释放。手动启动的后台仍由托盘退出，不随 Plasticity 窗口关闭。

## 组件浏览与编辑

控制中心的“左侧导航”可切换固定展开与悬停展开。悬停模式仅保留窄栏，移入鼠标展开导航，移出后收起；展开覆盖组件区域，不挤动组件网格。该设置自动保存，与面板的位置设置独立。

控制中心的“面板位置”可直接切换固定位置与鼠标位置，设置自动保存在本机并在后台重启后保留。鼠标模式在每次 Tab 打开时以鼠标为面板中心；靠近边缘时调整位置，保证面板完整显示在 Plasticity 窗口内。打开后不跟随鼠标移动。首次升级该功能需重新启动 Plasticity 加载新版内嵌入口。

- Tab 打开或关闭内嵌面板；点击缩略图直接置入。按住右键并移动鼠标可在临时正交预览中旋转查看，松开恢复。
- 点击卡片“编辑”后，侧栏直接展示名称、库、分组、类型、分类、标签、备注、预览图和默认置入模式；修改后点击“保存修改”。侧栏内容超出窗口时独立滚动。
- 每个组件可以保存独立对象、布尔合并、布尔减去或布尔相交模式。布尔置入前先选中目标实体，再打开面板置入；使用原生定位与确认流程。没有目标或插件版本过旧时会拒绝布尔置入，原位置粘贴始终保持独立对象。
- 缩略图与三维预览都使用正交视图。界面采用中性黑灰色，操作说明以悬停提示为主。

## 启动

在项目目录的 PowerShell 中运行：

```powershell
.\start.ps1
```

脚本构建 Solid 前端并启动本地服务，默认使用 `pythonw.exe` 在后台运行，并在独立 Edge 应用窗口打开控制中心；没有 Edge 时回退到浏览器。WebUI 同时可通过 `http://127.0.0.1:15150/?control=1` 访问。Windows 通知区域有带状态圆点的组件库立方体图标；若图标被 Windows 折叠，点击任务栏的隐藏图标箭头即可找到。需要 Node.js/npm 和 Python 3.10+；脚本会尝试项目虚拟环境、Codex 自带 Python 和已安装的 Python。项目内的旧虚拟环境即使原解释器丢失，也可以复用其纯 Python Tornado 包。

使用独立 Python 环境时：

```powershell
python -m pip install -r requirements.txt
cd plasticity-asset-tool-app
npm install
npm run build
cd ..
python main.py
```

已有构建可运行 `.\start.ps1 -NoBuild`；`-Headless` 只启动服务。服务只监听本机。应从普通桌面终端启动，以便读取本机 Plasticity 窗口；开发沙箱可能无法枚举桌面进程。

## 后台图标与控制中心

按 FigJam 画布中的“后台维护窗口连接、组件分类搜索与快速置入”思路，控制中心与模型组件库使用同一套侧栏、立方体标识和颜色。画布是功能草图，本次增加的控制中心是对这一流程的具体实现。

- 双击托盘图标打开控制中心；右键菜单可以打开控制中心、查看模型组件库、刷新连接、暂停/恢复模型连接和退出后台服务。
- 控制中心是有标题栏、最小化和关闭按钮的独立窗口；重复打开会复用已有窗口。WebUI 中的“打开独立窗口”可切换到此窗口。Edge 使用项目 `.runtime/control-window-profile` 的独立配置目录。关闭管理窗口保留后台，托盘可再次打开。
- 绿色圆点表示模型操作启用，黄色表示暂停。悬停查看运行状态、窗口数量和组件数量；Windows Explorer 重启后会重新注册图标。
- 控制中心显示后台运行时长、可用 Plasticity 窗口、组件与组件库数量、面板连接数、Tab 快捷键及托盘状态。可切换到原生模型窗口，再按 Tab 使用内嵌面板；“查看组件库”可浏览组件详情、搜索、分类及预览。
- 暂停会阻止后台发送模型操作、置入和自动复制选中实体，浏览与整理组件仍可用；不会关闭 Plasticity，也不会取消其正在进行的原生工具。恢复后重新启用操作。
- 关闭控制中心页面会保留服务。点击“退出后台服务”有明确提示；托盘的退出选项可直接退出。退出会等待当前后台模型操作结束，释放端口、关闭面板连接并移除托盘图标，组件数据保留。重新运行启动脚本即可恢复。
- `-Headless` 不自动打开页面，但保留托盘；`-Console` 保留命令行窗口，`-NoTray` 使用纯命令行模式。没有 `pythonw.exe` 时回退到控制台运行。日志写入 `.runtime/service.log`。重复启动会复用已有服务，不创建第二个托盘图标。

## 保存和置入组件

组件浏览器按画布草图优先展示组件：顶部搜索和类型切换、左侧窄栏管理资产库与分组，主区域为全宽组件网格。连接与分组设置按需展开；组件详情点击预览或名称后以侧边弹层打开，关闭后恢复完整网格。底部可按保存时间或名称排序，并通过滑块调整卡片大小。已构建并验证详情开关、设置入口、排序与大小调整。

保存组件默认开启“自动生成几何预览”：解析原始剪贴板中的 Parasolid 数据块，由已授权且已初始化的 Plasticity 内核在独立上下文、临时分区中读取和三角化，完成后回退临时分区。Three.js 渲染组件自身的面和边线，以正交投影生成 512×512 缩略图，保持斜向观察角度并按模型包围范围留边；顶部“生成预览”可从缓存网格重新渲染已有缩略图。详情页支持拖动旋转与滚轮缩放。预览不截取建模视口，不向文档置入对象，不改变选择、视角或剪贴板。手动上传的图片仍优先用于卡片。

网格与缩略图按原始模型 SHA-256 缓存在数据库中，重复组件共用缓存；已缓存预览在 Plasticity 关闭后仍可浏览。首次生成需要运行已加载新版内嵌插件的 Plasticity。现有组件可点击顶部“生成预览”批量补全，也可打开详情自动生成。转换失败仍保留已保存的模型并提示原因；最多支持每组件 256 个对象、2 百万个网格数值。组件包保留原始模型及上传的图片，几何缓存可在导入后重新生成。

1. 打开源 `.plasticity` 模型，选中需要复用的实体或多个实体，完成当前工具。
2. 打开组件库，点击“保存组件”，填写名称、分类、标签和备注。可附加 JPEG 预览图。
3. 选择已连接内嵌插件的 Plasticity 窗口，点击组件卡片的“置入”。工具把原始模型字节通过本地任务通道传给该窗口的原生放置命令。
4. 在 Plasticity 视口点击定位。置入期间可按 **S** 缩放（例如输入 `2` 放大两倍）、**A** 调整角度、**D** 偏移；**F** 翻转，**X/Y/Z** 调整朝向。数值调整按 Enter 确认，再按 Enter 完成置入。原生工具会继续等待下次定位，可重复置入，**Esc** 退出。后续可用组件库的移动、旋转、缩放按钮调用原生工具。

有可用目标窗口时，“保存组件”默认开启“直接保存选中的模型”：读取选中对象的原生编码，校验后保存，不发送 Ctrl+C。内嵌面板保存完成后会重新显示。取消勾选可以从手动复制的剪贴板保存；“仅复制到剪贴板”仍是明确的手动交换入口。“原位置粘贴”通过原生命令直接接收内存数据。

原生传输适配器在同步编码/解码调用期间，把 Electron 的模型格式检查、读写函数绑定到内存缓冲区，退出调用时立即恢复；不会调用系统剪贴板，也不要求剪贴板里已有模型。置入仍通过编辑器的命令执行器，保留定位、取消、撤销与重做。每次组件库点击置入一个组件，确认后仅结束该模型缓冲区对应的空白连续放置命令，不干扰其他工具。窗口身份按 HWND 绑定，工作任务只派发一次；未连接、模型损坏或正在使用建模工具时拒绝操作，不自动退回剪贴板方式。错误提示只显示可读信息，不显示内部路径或堆栈。接口依赖 Plasticity 内部实现，目前实机验证版本为 Windows 26.1.3。

多窗口内嵌面板固定绑定其所属 HWND，不因桌面窗口枚举暂缺而清空目标或切换到另一份文档。后台将实时原生插件连接补充到窗口列表；次级 Electron 会话也加载插件。独立 WebUI 的“跟随激活窗口”在点击置入时解析最近激活的 CAD 窗口，切到 WebUI 后仍保留该目标；手动固定窗口则保持选择。已用两份隔离 Plasticity 实测各自置入、激活跟随、独立 Tab 开关及撤销后模型摘要一致。

2026-10-04 已实机验证保存与置入前后系统剪贴板序号不变，定位置入及原位置入均可撤销/重做，测试场景原有六个实体的序列化摘要一致，Tab 连续开关正常。原生传输入口的回滚备份为 `.runtime/plasticity-formal-main-before-native-transport.js`。安装后下次启动 Plasticity 生效；不会强制关闭当前文档。

保存、复制和置入会校验 Plasticity 专用剪贴板格式、数据长度，以及已观察到的 26.x 二进制封装（变换数值、长度边界、JSON 元数据、实体数量和 Parasolid 标识）。置入前还会检查组件 SHA-256 摘要，并回读剪贴板核对原始字节；格式不符、结构损坏、未知编码或剪贴板被替换时不发送粘贴命令。校验不会修改原始字节，也不替代 Plasticity 内核的几何合法性检查。当前两个本机组件通过结构检查，76 项测试通过，包含非法数据、截断、摘要损坏与剪贴板替换的拦截测试。

## 组件库和备份

- 资产库标签支持新建、切换和重命名；旧组件自动归入“默认库”。每个库独立显示组件、分类、分组和归档数量，仍统一保存在同一个 SQLite 数据库中。
- 库内支持嵌套分组，侧栏和路径导航可以进入子分组。保存或编辑组件时可选择所属库、分组，以及 Solid / Curve / 混合 / 未标注类型；跨库移动保留原始模型字节，导入组件包使用当前库和当前分组。
- 分组是组件库的组织结构，类型由用户标注。目前不会自动解析或恢复 Plasticity 原生组树、对象 ID、对象名称，也不提供自动布尔。分组内的子组件可以独立置入；分组本身不会自动合并为一个模型。
- 搜索覆盖当前库的所有分组；Ctrl+K 聚焦搜索，Enter 置入第一项结果，随后仍需在 Plasticity 视口定位并确认。

- 数据保存在 `library/library.sqlite3`，包含原始模型字节、元数据和可选 JPEG 预览；该目录不会进入 Git。关闭服务后复制整个 `library` 目录即可备份。
- 支持分类与搜索、编辑信息、归档和恢复。归档保留模型数据。编辑组件时可以替换或移除 JPEG 预览图；只编辑信息会保留原图。列表和预览请求只读取所需数据，避免每次刷新都加载全部模型字节。
- 单组件可以导出 `.patasset` 包再导入，导入会校验模型摘要。原生剪贴板格式是 Plasticity 内部格式，跨版本、跨电脑和 Windows 重启后的兼容性尚未实机验证。此包不是通用 CAD 交换格式。
- 目前 `.plasticity` 文件需先在 Plasticity 打开并复制所需实体；组件库不会把一个完整文档直接当作实体插入，也不会替换目标文档。

## 快捷唤起

Windows 服务运行期间，在 Plasticity 前台按 **Tab** 打开组件库并聚焦搜索；面板打开时再按 **Tab** 关闭并交回建模窗口，**Esc** 或右上角 × 也可收起。Tab 仅在 Plasticity 或它的组件库面板前台生效；其他应用、Shift+Tab 和 Ctrl+Tab 不受影响。面板中的单独 Tab 优先切换开关，可用 Shift+Tab 或鼠标选择表单字段。长按不会连续切换。使用 Tab 会覆盖 Plasticity 原有的同键功能，如需保留请更换唤起键。

当前配置使用真正的 iframe 内嵌模式，通过下面的 main 入口补丁安装到 Plasticity 建模窗口。`launcher.enabled: false` 避免旧的桌面 Tab 钩子抢占按键。本地服务仍需要运行，可使用 `.\start.ps1 -Headless -NoBuild`。如需原来的 Edge 无边框附属浮层，应先恢复 main 入口，再启用 `launcher.enabled`；该浮层模式不是 DOM 内嵌。

组件库触发置入、复制选中实体或建模快捷键时会收起并交回所选 Plasticity 窗口。服务确认目标窗口获得焦点后才发送按键，切换失败会恢复组件库并报错。仅收起标题和进程匹配的组件库 Edge 窗口，不收起其他浏览器页面。2026-10-03 已实测从前台独立窗口交还焦点并进入 Ctrl+Shift+V 原生定位工具，取消测试后原有三个实体保留。

`config.json` 的 `launcher.enabled` 关闭唤起功能，`launcher.shortcut` 更换为 `tab`、`f8`、`ctrl+alt+space` 等（修改后重启服务）；`launcher.frameless: false` 恢复独立有边框窗口。单键使用只针对 Plasticity 的键盘钩子，组合键使用 Windows 快捷键注册；注册失败会在页脚提示。服务退出时释放钩子/快捷键并恢复组件库原来的窗口样式。`-Headless` 不自动打开浏览器，但保留按键唤起功能。

## 真正的内嵌面板

`main_embed_install.py` 在 `resources/app/.webpack/main/index.js` 前添加 Electron 加载钩子，保留原始编译加载器字节和 `index.compiled.jsc`。建模页面完成加载后注入 iframe，默认隐藏，第一次 Tab 才加载组件库。不修改 renderer HTML，也不需要 CDP。每个窗口的 URL 自动带上它自己的 HWND，避免将组件发到其他建模窗口。

Tab 在 Electron 输入层处理，并兼容原生/模拟输入的 `code` 和 `key`，忽略组合键及长按重复；面板获得焦点后仍可再次 Tab 关闭。首次加载通过 `pat:ready` 握手，避免向尚未加载的子页面发送消息。置入前隐藏 iframe、聚焦 CAD 画布，收到焦点确认后发送 Ctrl+Shift+V；操作失败时重新显示面板和错误提示。Esc / × 也可收起。

安装前关闭 Plasticity，在有安装目录写权限的终端运行（替换版本路径）：

```powershell
python main_embed_install.py --target "C:/Program Files/Plasticity/app-26.1.3/resources/app/.webpack/main/index.js" --backup ".runtime/plasticity-formal-main-original.js"
```

使用内嵌模式时将 `launcher.enabled` 设为 `false`；`keymap.show_panel_event_key_code` 指定按键，如 `Tab` 或 `F8`，改键后需要先恢复入口，再重新安装补丁并重启 Plasticity。服务继续使用 `.\start.ps1 -Headless`。正式安装不要传 `--profile`，它只用于测试副本的 Electron 配置隔离。

恢复入口使用 `python main_embed_install.py --restore --backup ".runtime/plasticity-formal-main-original.js"`，需要安装目录写权限（通常需管理员终端或手动确认 Windows UAC）。备份和 manifest 记录原始、补丁 SHA-256；恢复会拒绝覆盖补丁之后的其他修改。Plasticity 更新后应检查新的版本入口并使用新的备份路径。旧 `embedded_install.py` 的 HTML 方案保留为实验脚本，当前不使用。

另一条路径是配置 `plasticity.cdp_endpoints` 为已有的本机 CDP 地址。检测到调试页面后会出现单独的 CDP 目标和“嵌入面板”按钮，同样使用 iframe，重复安装复用原面板；此路径不修改安装文件。

本机安装版本为 26.1.3。2026-10-03 已在真实 Plasticity 测试副本中验证 iframe 内嵌、两次无调试参数启动、Tab 重复开关、Esc 收起，以及原生组件置入、S 输入 2 放大两倍、确认新增实体和撤销。经用户批准已安装正式 main 补丁，正式窗口也完成两次无调试参数启动、插件加载、Tab 打开/关闭，以及置入、两倍缩放和撤销验证。测试受限沙箱中的 GPU 子进程加载失败，而完整桌面权限下正常启动成功。验证限于本机当前版本，跨版本、跨电脑和长期运行尚未验证。启动记录保存在 `.runtime/formal-embedded-startup-1.log`、`.runtime/formal-embedded-startup-2.log`，安装备份为 `.runtime/plasticity-formal-main-original.js` 及其 manifest。

## 有来源说明的 Windows 插件安装器

使用 `install-plugin.ps1` 安装或升级入口，替代直接对 PowerShell 请求管理员权限。脚本构建带项目图标和名称的 `Plasticity 模型组件库插件安装.exe`，先显示项目来源、本次更新内容、目标文件、回滚备份和管理员权限的用途，再由这个安装器向 Windows 请求权限。来源为本开源项目，未签名时 Windows 仍会显示未知发布者；不将其标记为 Plasticity 官方发布者。

安装器参数与 `main_embed_install.py` 对应：`-Target`、`-Backup`、`-UpgradeFrom`、`-BaseBackup`，恢复时使用 `-Restore -Backup`。`-Description` 用于填写此次具体更新，例如“更新组件默认布尔置入：独立、合并、减去、相交”。首次安装不传升级参数；升级必须使用与当前入口匹配的已验证备份。取消说明窗口或 UAC 时不执行安装。

`-BuildOnly` 只构建安装器；`-Preview` 生成 `.runtime/plugin-installer-preview.png`，不申请权限、不写入 Plasticity。构建使用 Windows 自带 .NET Framework 4 编译器。日常后台运行、Tab 面板、组件保存和置入不需要管理员权限。
